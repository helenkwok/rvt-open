rvt-open reads Autodesk Revit project, family and template files (.rvt, .rfa, .rte, .rft) without Revit: their elements, geometry, materials and parameters. Walk the model in your browser, or convert it to open formats from the command line.

One file in. Open formats out.

It reads Revit releases 2008 to 2027, and decodes elements from 2010 on. Every export prints diagnostics saying what was approximated or left out; read them before using a file for measurement or coordination. rvt-open reads Revit files; it does not write them.

In the browser

The viewer opens a Revit file inside the page with the WebAssembly build. Nothing is uploaded: the file is parsed in the tab and discarded when the tab closes. The page has no analytics, no CDNs and no telemetry, and its Content-Security-Policy limits connections to the page's own files. See the viewer privacy posture.

  • Scene tree, categories and element properties
  • Export IFC, glTF, 3D PDF, plan SVG and CSV schedules
  • No account, no upload

In the browser, wasm32 has a 4 GiB memory ceiling, so files over about 130 MB can exceed it. Use the command line for those.

On the command line

Command-line tools, a Rust library, Python bindings and a WebAssembly package. --help on any tool lists its options.

# release, worksharing, previews, schema summary
$ rvt-info my-project.rvt
$ rvt-ifc my-project.rvt -o out.ifc \
    --ifcx out.ifcx --frag out.frag --usda out.usda --usdc out.usdc
$ rvt-gltf my-project.rvt -o out.glb
$ rvt-gltf my-project.rvt --format pdf3d   # writes my-project.pdf
$ rvt-sheet my-project.rvt -o plan.svg
$ rvt-schedule my-project.rvt              # schedules as CSV

Verifying downloads

Each release archive has a build provenance attestation, an entry in SHA256SUMS, a CycloneDX SBOM and a Trivy report, and releases built with VirusTotal enabled list each archive's VirusTotal report in virustotal.md. To check that an archive was built by this repository's release workflow:

gh attestation verify rvt-open-vX.Y.Z-x86_64-unknown-linux-gnu.tar.gz -R helenkwok/rvt-open

To check the checksum of the files you downloaded:

sha256sum -c SHA256SUMS --ignore-missing

SECURITY.md covers every check, and how to report a vulnerability privately.
