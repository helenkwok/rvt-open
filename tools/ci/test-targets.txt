# Which tests/*.rs targets CI and tools/check-local.sh run, and why.
#
# Unit tests are not used in this repository: no new ones, and none run in CI or the local gate.
# What runs is verification against real Revit files, end-to-end runs of the
# built CLIs, and contract checks that keep published claims honest. Every
# tests/*.rs target must appear here exactly once, so a new target cannot
# silently run or silently skip; tools/ci/verify-real-files.sh fails when one
# is missing.
# Each target is a module of tests/integration/main.rs, one test binary,
# so its tests are named <target>::<test>.
#
# Format: <class> <target> [skip=<test name substring>,...]
#   real      reads real Revit files from the corpora and checks what the
#             reader or exporter gives against the file or Revit's own export
#   cli       runs the built binaries end to end
#   contract  checks a published claim (support matrix, binary inventory,
#             witness verdicts, JSON schemas, field-type coverage, the
#             committed synthetic IFC fixtures) against the code and artifacts
#   hardening replays inputs that crashed or overran a parser of untrusted
#             files (fuzz findings) through the public API: run, as a
#             parser of hostile input must keep surviving them
#
# `skip=` leaves out the synthetic-fixture tests inside a real-file target.
#
# One end-to-end test is not a target of that binary: the MCP server's, in its
# crate, rvt-open-mcp/tests/mcp_stdio.rs. Its class is
#
#   cli       mcp_stdio     (rvt-open-mcp: the built server over real stdio)
#
# but it is not listed below, because this manifest names the tests/*.rs
# targets of the root crate and the script above fails on one that is not
# there. ci.yml runs it in its own step ("MCP server end to end", in the test
# matrix on every OS, and again in Corpus health on Einhoven), and
# tools/check-local.sh runs `cargo test -p rvt-open-mcp`.

#
# Public CI skips (rvt-open-public-export): these tests need files with no public source.
#   beam_storeys::ifc_beam_storeys_match_revit_export: needs Revit's own IFC export of the 2024 samples, which has no public source
#   beam_system_params::beam_system_values_equal_revits: needs Revit's own IFC export of the 2024 samples, which has no public source
#   export_conventions::framing_class_follows_the_convention: needs Revit's own IFC export of the 2024 samples, which has no public source
#   export_conventions::no_rule_beam_storey_follows_the_convention: needs Revit's own IFC export of the 2024 samples, which has no public source
#   export_conventions::model_without_storeys_follows_the_convention: needs Revit's own IFC export of the 2024 samples, which has no public source
#   witness_registry::ifc_lite_gate_is_wired_and_version_pinned: checks a step of the private CI workflow that the public CI does not have
#   witness_registry::ifcopenshell_gate_script_is_wired: checks a step of the private CI workflow that the public CI does not have
