- **Names Revit keeps in its program, in 13 languages.** `program_names`
  holds the names of built-in categories and subcategories and of system
  families, taken from Revit 2027's public help in each of the 13 languages
  it offers (ENU, CHT, CHS, CSY, DEU, ESP, FRA, ITA, JPN, KOR, PLK, PTB,
  RUS), each entry citing its help topic. A graphics style of a built-in
  subcategory and a system family's types are now named in the language the
  file was saved in (`BasicFileInfo`, "Locale when saved"), English where it
  stores none.
