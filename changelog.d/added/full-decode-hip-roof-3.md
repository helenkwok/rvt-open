- **Built-in parameters read from an element's fields.**
  `field_parameters` gives the parameters Revit shows from an element's
  header (category, design option) and, through 367 (class, parameter,
  field) rules, from its own fields. On `1-hip-roof` (Revit 2024) the
  parameter values that match the Revit API rise from 2,076 to 24,711 of
  37,420: 16,518 from the header and 6,117 from fields, beside the stored
  ones.
