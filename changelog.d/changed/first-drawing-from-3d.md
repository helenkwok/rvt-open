- **The viewer's first drawing is drawn from the exporter's model, kept by the open.** The first sheet or view drawn after a file is opened exported the whole file a second time. The open now keeps a copy of the exporter's own model (before the later passes), and the first drawing takes it: the same model `rvt-sheet` draws from. `rvt-sheet --viewer-model` draws from the model the open keeps, and `ExportOptions::with_keep_base` asks for it.
