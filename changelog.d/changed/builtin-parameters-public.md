- **The built-in parameter catalog comes from public sources only.** Each field of an entry now has one source, named in its source column: the Revit 2027 API reference (name, enum name), the values public sample files store (storage type), Revit's own IFC export of public samples (spec, group, enumeration texts) and machine-matched Revit 2027 help terms (names in the 12 other languages, `builtin_parameters::localized_name`, cited per entry). A field no public source gives is empty: of the ids the Revit API dump held, 1,903 storage types, 849 specs, 297 groups and 1,214 enumeration texts are no longer filled, and category names are the help's (`program_names`) only. Seven ids no public source names are kept with an empty name. The dump is the answer key only: `tools/builtin-parameters/score.py` scores the table against it per field, and `tests/builtin_catalog_sources.rs` pins how many fields each source fills. `field_parameters` takes the storage type of a field's value from the field's own kind.
