- **A wall profile region that a pocket equals stays that pocket.**
  A region of a wall's edited elevation profile that one of its pockets equals
  is written as that pocket's opening, with the wall left whole. The
  pass that carries a region on to the wall's end carried such a region
  too, after which it no longer equalled the pocket, so it was cut into the
  wall's body: the one case the profile rules say must not happen. A region a
  pocket equals is no longer carried.
