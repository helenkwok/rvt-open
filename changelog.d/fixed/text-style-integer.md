- **Bold, italic and underline of dimension and spot elevation styles are integers.** `TEXT_STYLE_BOLD`, `TEXT_STYLE_ITALIC` and `TEXT_STYLE_UNDERLINE` are kept as an integer in the Int set of some elements and as a whole-number float in the Double set of others (148,932 entries each on the 101 public sample files, none with a fraction); `SchemaObject::stored_parameters` and `nested_parameters` returned the float as a `Double`, where Revit shows an integer. They now return the integer. Revit's API reports an integer for all 2,382 values of these three parameters that the dump of the public samples holds.
